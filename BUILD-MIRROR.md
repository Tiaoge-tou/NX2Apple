# Build mirror

This repository is a byte-for-byte copy of Tiaoge-tou/NX2Apple at commit 54a82b0a, created on 2026-11-04 because GitHub disabled Actions on the original repository (workflow_dispatch is refused there with HTTP 422, "Actions has been disabled for this repository", while its settings show Actions allowed).

It exists only to run the Build IPA workflow. Its main is not developed on: every change lands in Tiaoge-tou/NX2Apple by pull request first and is copied over. Releases published here are the deliverables of that project while the original repository cannot build.
